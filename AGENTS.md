# AGENTS.md — DineReserve

Built on @agntdev/bot-toolkit with grammY + TypeScript.

## Setup
```bash
npm install
npm run build
```

## Running
```bash
BOT_TOKEN=your-token npm start
```

## Development
```bash
npm run dev
```

## Testing
Dialog tests: `tests/specs/*.json` — BotSpec arrays.
Command declarations: `tests/commands/*.json` — JSON string arrays.
